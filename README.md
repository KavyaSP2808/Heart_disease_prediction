🫀 Heart Disease Analysis and Prediction

📌 Description

This project focuses on predicting the presence of heart disease in patients using clinical and demographic data. It leverages exploratory data analysis (EDA), data preprocessing, and machine learning algorithms to build an accurate and reliable prediction system.

The project includes:

Data cleaning and handling missing values

Exploratory Data Analysis (EDA) and feature correlation analysis

Feature scaling and preprocessing

Model training using multiple classification algorithms

Hyperparameter tuning for performance optimization

Ensemble learning techniques to improve prediction accuracy

📊 Dataset

The dataset contains medical attributes such as:

Age,
Sex,
Chest pain type,
Resting blood pressure,
Cholesterol level,
Fasting blood sugar,
Resting ECG results,
Maximum heart rate achieved,
Exercise-induced angina,

These features are used to predict whether a patient is at risk of heart disease.

📈 Results

Best Performing Model: VotingClassifier

Accuracy Achieved: ~73%

ROC AUC Score: ~82%

The ensemble approach provided better generalization compared to individual models.
